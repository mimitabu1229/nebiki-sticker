# 無限に値引きシール係。

スーパーの夜、消費期限が近づいた惣菜に、割引シールを貼り続けるだけの、無料のブラウザミニゲームです。ゴールも失敗もなく、単調な作業の心地よさを楽しむゲームです。

**遊ぶ: https://nebikigames.com/**

- ダウンロードや登録は不要。パソコンでもスマホでも、ブラウザだけで遊べます。
- 貼ったシールの枚数が増えると、ライバルの店員「たなか」、シールはがし爺の「やまだ」、パートさんの「いくえ」、店長の「おださん」（シール貼り銃）、お掃除ロボットの「シリボ」、アメリカ人店員の「ジョン」が、売り場に現れます。
- くわしくは、[遊び方と解放条件](https://nebikigames.com/how-to)、[キャラクター紹介](https://nebikigames.com/characters)、[更新情報](https://nebikigames.com/changelog) をご覧ください。

## 仕組み

HTML・CSS・JavaScript だけで作られた、1つのページです。外部のゲーム用ライブラリは使っていません。効果音は Web Audio、書体は Google Fonts を使っています。Cloudflare Pages で配信しています。

## English

**Infinite Discount-Sticker Clerk** is a free, relaxing browser game. At night in a Japanese supermarket, you keep putting discount stickers on food that is close to its expiry date. There is no goal and no game over. Play it here: https://nebikigames.com/
